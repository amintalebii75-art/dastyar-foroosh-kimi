# 🛒 دستیار فروش | Dastyar Foroosh

یک اپلیکیشن وب سبک و کامل برای مدیریت مشتریان، سفارشات و محصولات — کاملاً آفلاین و بدون نیاز به سرور.

## ✨ ویژگی‌ها

- 📊 **داشبورد هوشمند** — آمار فروش، نمودار هفتگی، پیشنهادات هوشمند
- 👥 **مدیریت مشتریان** — دسته‌بندی A/B/C، یادداشت، علاقه‌مندی‌ها
- 📦 **کاتالوگ محصولات** — قیمت‌گذاری سه‌سطحی (خرید / عمده / خرده)
- 📝 **ثبت سفارش** — سبد خرید با محاسبه مالیات خودکار
- 💾 **ذخیره‌سازی محلی** — همه داده‌ها در مرورگر (localStorage)
- 📤 **خروجی JSON** — پشتیبان‌گیری و بازیابی آسان
- 🌙 **طراحی مدرن** — رابط کاربری تمیز با فونت Vazirmatn

## 🚀 اجرا

فقط فایل `index.html` را در مرورگر باز کنید. نیازی به سرور یا نصب نیست!

```bash
# یا با یک سرور محلی:
npx serve .
```
